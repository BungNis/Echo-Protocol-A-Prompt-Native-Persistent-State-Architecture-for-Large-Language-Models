# Echo-Protocol-A-Prompt-Native-Persistent-State-Architecture-for-Large-Language-Models
Prompt-native persistent state architecture for LLMs. No backend. No vector DB. No fine-tuning. One file.

Echo Protocol V7
Start here: [Echo_Protocol_Paper_EN_v2.pdf]
Read the paper first. It explains what this is, why it was built this way, and what the design decisions mean. The prompt file will make much more sense after.

After reading the paper
Echo_Protocol_ProjectV7.md is the complete system. One file. Paste it into any LLM as a system prompt and type Start.
The prompt is not written for humans to read — it is written for the model to execute. Dense by design. Token-efficient by necessity. The paper is the documentation.
Status
Early-stage. One developer. One model tested (DeepSeek, free tier). One domain validated (interactive narrative as stress-test environment).
The architecture generalizes. The limits are not fully mapped. Community replication is the point.
What the community can do

Test on other models and report results
Fork the Tracker format for other domains (project management, game logic, industrial control)
Implement the Dual-Agent External Memory extension proposed in the paper
